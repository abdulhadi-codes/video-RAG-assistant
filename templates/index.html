What's running under the hood

◈

Semantic Search

Questions are matched by meaning, not keyword overlap — vector similarity finds the right moment even when your phrasing differs from the lecture's.

▤

Context Retrieval

The top-matching transcript chunks are pulled with their video number and timestamp attached, so every answer stays traceable.

✦

LLM Generation

Retrieved context is passed to a language model that writes a direct answer instead of a wall of matching transcript text.

⌘

Course Intelligence

The whole course becomes one queryable knowledge base instead of eighteen separate video files.

◐

Whisper Transcription

Every video's audio is transcribed to timestamped text, forming the raw material the rest of the pipeline searches over.

▧

Vector Storage

Chunk embeddings are persisted so retrieval never has to re-process the course from scratch.

About this project

CourseMind AI is a Retrieval-Augmented Generation system built end-to-end: audio extraction, Whisper transcription, chunking, embedding generation, vector retrieval, and LLM-based answer synthesis, wired into a Flask application with a live UI.
